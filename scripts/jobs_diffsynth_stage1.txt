# Diffsynth, stage 1: P-loss and the four pretrains.
#
#   python scripts/gpu_queue.py --jobs scripts/jobs_diffsynth_stage1.txt
#
# Two stages rather than one because the resumes depend on the pretrains and
# gpu_queue.py has no notion of dependencies. Stage 1 is five independent runs;
# stage 2 is the eight resumes, launched once these have finished.
#
# One GPU per arm. See scripts/ds_run.sh for why not DDP -- in short, batch_size
# is per-device under DDP, so four cards would give 62 steps/epoch instead of
# 250 and move the ramp off the paper's epochs 50/200.
#
# The four loss variants, all under the paper's own switch schedule:
#
#   hybrid     their loss, mag_w = log_mag_w = 1        the reproduction
#   mag        log_mag_w=0, the linear half alone       the claim
#   log        mag_w=0, the log half alone              the other half
#   mag_halfw  log_mag_w=0 AND sw_w end_v 1.0 -> 0.5    the normalisation control
#
# mag_halfw exists because loss.py:60 divides by len(fft_sizes)*(mag_w +
# log_mag_w). Zeroing log_mag_w takes the divisor from 12 to 6, so the surviving
# magnitude term carries twice the weight it had inside the hybrid. Adam would
# absorb a constant, but gradient_clip_val=1.0 does not, and the ramp mixes the
# spectral loss against param_w 10->0. Halving sw_w restores 1/12 per term
# exactly. If mag and mag_halfw agree, one sentence disposes of the objection;
# if they do not, the scale is doing work and we need to say which reading we
# report.
#
# P-loss runs 400 epochs and the pretrains 200, so P-loss occupies its card for
# roughly twice as long -- it is listed first so it starts earliest.
scripts/ds_run.sh ploss           ploss    "{gpu}"
scripts/ds_run.sh pre_hybrid      pretrain "{gpu}"
scripts/ds_run.sh pre_mag         pretrain "{gpu}" model.sw_loss.log_mag_w=0
scripts/ds_run.sh pre_log         pretrain "{gpu}" model.sw_loss.mag_w=0
scripts/ds_run.sh pre_mag_halfw   pretrain "{gpu}" model.sw_loss.log_mag_w=0 schedule.sw_w.end_v=0.5
