# Learning rate as a stated grid, queued onto cards as they free.
#
#   python scripts/gpu_queue.py --jobs scripts/jobs_lr_probe.txt
#
# 15 cells = 3 losses x 5 rates, 12000 steps each, constant rate (lr_floor=1,
# lr_hold_frac=1 inside lr_probe.sh) so "this rate fails" is not confounded with
# "this schedule fails". norm=batch, tanh, adam_eps=1e-8 -- matching the ladder
# re-run, so the two are readable against each other.
#
# Why these three losses:
#
#   L1_STFT_eps1    the target. It is the only log arm still MOVING at 40k
#                   (0.0885 -> 0.0789 from step 26k), so "slow, not stuck" is
#                   live for it and "you did not tune the rate" is a fair hit.
#                   Note it is still above the constant-predictor floor of
#                   0.0473 -- ratio 1.67 -- so it has not beaten the mean yet.
#   L1_STFT         the control, and not optional. The claim is that linear is
#                   as insensitive to rate as log is; without the control on the
#                   same axis that is an assertion rather than a measurement.
#   L1_STFT_eps1e1  a dead arm, flat at 0.1841 for the last 10k steps. One of
#                   each kind in the grid.
#
# Why these five rates: 3e-4 is the ladder's, so a decade either side. Both
# directions matter for different reasons -- a still-descending arm plausibly
# wants MORE rate, a collapsed one plausibly wants less -- and probing only
# downward invites exactly the objection this grid exists to close. 1e-5 is
# omitted: two decades down at a 12k budget produces undertrained cells that
# say nothing about the rate.
#
# Known limitation, to be stated in the caption rather than found by a reviewer:
# at fixed 12000 steps the low-rate cells are budget-limited, so a poor result
# at 3e-5 conflates "wrong rate" with "not enough steps". Equal budget per cell
# is still the right call; it just has to be declared.
#
# Report best-per-arm, not best-overall.
#
# Ordering: eps1 first, then the control, then the dead arm. A queue that only
# gets two thirds of the way still answers the live question.

# --- eps1: the arm still descending, i.e. the one the objection is about ---
