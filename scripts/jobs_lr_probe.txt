# Is eps1's failure an artifact of the learning rate? Queued onto free cards.
#
#   python scripts/gpu_queue.py --jobs scripts/jobs_lr_probe.txt
#
# Four cells: eps1 at a decade either side of the ladder's 3e-4. Nothing else
# is set on these lines because scripts/lr_probe.sh defaults to the eps ladder's
# recipe exactly -- 40000 steps, cosine to a 0.02 floor from 60% of the run,
# norm=batch, tanh, adam_eps=1e-8, batch 64, clip 5000, warmup 2000, same
# datasets, same numerics, same seed. Learning rate is the only difference
# between a cell here and an arm of the ladder, which is what makes the two
# quotable side by side.
#
# eps1 alone, on purpose. The claim being defended is narrow -- that eps1's
# result is not a rate artifact -- and eps1 is the only rung that claim is live
# for: it is still descending at 40k (0.0885 -> 0.0789 over the last 14k steps)
# where eps1e1 and eps1e3 are flat to four digits. Sweeping linear and eps1e1
# too would support a broader claim, that linear is no more rate-sensitive than
# log; that is a different argument and costs 8 more cells.
#
# 3e-4 is absent because at the ladder's own rate the cell reproduces the
# ladder arm bit for bit, seed included. Take it from
# results/ddsp/eps_ladder_adam1e8/L1_STFT_eps1.
#
# What answers the question: if no rate in the grid brings eps1 under the
# constant-predictor floor of 0.0473, the rate is not the explanation. If one
# does, the ladder has to be restated at the per-arm best rate rather than a
# shared 3e-4 -- more work, but the honest version.
#
# Caption note: equal budget per cell means the low-rate cells are the least
# converged, and the cosine decays to 2% of peak so 3e-5 ends at 6e-7. A poor
# result there conflates "wrong rate" with "not enough steps". Equal budget is
# still right; declare it. Report best-per-arm, not best-overall.

LOSSES="L1_STFT_eps1" LRS="3e-3" scripts/lr_probe.sh "{gpu}"
LOSSES="L1_STFT_eps1" LRS="1e-3" scripts/lr_probe.sh "{gpu}"
LOSSES="L1_STFT_eps1" LRS="1e-4" scripts/lr_probe.sh "{gpu}"
LOSSES="L1_STFT_eps1" LRS="3e-5" scripts/lr_probe.sh "{gpu}"
