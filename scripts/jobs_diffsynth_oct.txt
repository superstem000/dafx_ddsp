# The published magnitude family, retrained on the octave-quantized dataset.
#
#   python scripts/gpu_queue.py --jobs scripts/jobs_diffsynth_oct.txt
#
# WHAT CHANGED. Only the data. configs/synth/dataset/h2of_oct.yaml draws MULT
# from {1, 2, 4} instead of uniform on (1, 8), so the second oscillator sits at
# unison or a whole number of octaves rather than an arbitrary ratio. The model
# synth is still h2of.yaml, ext_param_size is still 8, every loss setting below
# is copied verbatim from jobs_diffsynth_magx.txt and jobs_diffsynth_magx2.txt.
#
# WHY IT MIGHT MATTER. With a continuous ratio the model can place osc 2 at any
# interval and let the PAIR imply a fundamental that is neither oscillator's
# own. That is the behaviour heard on the real bass packs, where the pitch
# estimate tracks the true pitch at a slope well under 1 and the second
# oscillator sounds like noise. Octave-only removes the degree of freedom that
# makes it possible.
#
# THE BASE IS RETRAINED, not branched from pre_base. pre_base saw 50 epochs of
# the OLD distribution, and resuming the new arms from it would leave every arm
# initialised on data the experiment is trying to change. It is one extra
# 50-epoch job and it keeps the ladder internally clean.
#
# ID_DIR IS AN ENV VAR, not a hydra override. ds_run.sh already passes
# data.id_dir and hydra rejects a key given twice rather than taking the last.
# It is absolute on purpose: ds_run.sh checks the directory exists BEFORE it
# cds into external/diffsynth, so a relative path is resolved against
# whatever directory the queue was launched from.
#
# The three arms, all at per_term 1/12 so the comparison is weight-matched:
#   magx_halfw   mag only, sw_w 0.5
#   hybridx      mag + log, sw_w 1.0
#   logx_halfw   log only, sw_w 0.5
#
# log_eps_v=1e-2 goes with power=1: log_eps adds a fixed constant, and on
# magnitude the published 1e-4 would put the knee at p = 1e-8, four decades
# deeper. sqrt(1e-4) = 1e-2 holds it where the paper's loss had it.

# STAGE base
# 0 -> 50. One card, everything else waits on it.
ID_DIR=$HOME/dafx_ddsp/external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_oct scripts/ds_run.sh oct_base pretrain "{gpu}" trainer.max_epochs=50

# STAGE variants
# 50 -> 200.
ID_DIR=$HOME/dafx_ddsp/external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_oct RESUME=oct_base scripts/ds_run.sh oct_pre_magx_halfw pretrain "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.log_mag_w=0 model.sw_loss.power=1 schedule.sw_w.end_v=0.5
ID_DIR=$HOME/dafx_ddsp/external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_oct RESUME=oct_base scripts/ds_run.sh oct_pre_hybridx    pretrain "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.power=1 model.sw_loss.log_eps_v=1e-2
ID_DIR=$HOME/dafx_ddsp/external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_oct RESUME=oct_base scripts/ds_run.sh oct_pre_logx_halfw pretrain "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.power=1 model.sw_loss.log_eps_v=1e-2 model.sw_loss.mag_w=0 schedule.sw_w.end_v=0.5

# STAGE resumes
# 200 -> 400. synth only. The resume_real arms train on nsynth, which is not
# what any of this is measured on -- ds_eval_folder scores the SYNTH-stage
# checkpoints against the Juno / Korg / Moog packs.
ID_DIR=$HOME/dafx_ddsp/external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_oct RESUME=oct_pre_magx_halfw scripts/ds_run.sh oct_synth_magx_halfw resume_synth "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.log_mag_w=0 model.sw_loss.power=1 schedule.sw_w.end_v=0.5
ID_DIR=$HOME/dafx_ddsp/external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_oct RESUME=oct_pre_hybridx    scripts/ds_run.sh oct_synth_hybridx    resume_synth "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.power=1 model.sw_loss.log_eps_v=1e-2
