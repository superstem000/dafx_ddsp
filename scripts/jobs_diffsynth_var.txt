# The magnitude trio again, on notes that do not fill the clip.
#
#   python scripts/gpu_queue.py --jobs scripts/jobs_diffsynth_var.txt
#
# GENERATE THE DATASET FIRST, and check it, or this trains on the wrong thing:
#
#   scripts/ds_gen_varlen.sh
#   python scripts/ds_eval_folder.py \
#       --dirs external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var \
#              external/diffsynth/data/diffsynth_5-6/harmor_2oscfree \
#       --arms synth_magx_halfw --n 400 --seed 0 --device cpu
#
# The second command is the acceptance test, not a formality. The published set
# reports act_p10 0.958 and act_p90 0.998 -- every clip sounds from 0.000 s to
# 4.000 s. If the new set does not come back with a much lower act_p10 and a
# p90 still near 1.0, the window is not doing what it is supposed to and there
# is nothing here worth ~14 h of cards.
#
# WHAT IS DIFFERENT FROM jobs_diffsynth_magx2.txt. One thing: ID_DIR. The three
# losses, their weights, the schedule, the model synth and the estimator are all
# identical, so the linear-vs-log question is asked exactly as before on a
# training distribution that now contains short notes and notes that start late.
#
# THE DATA IS A SUPERSET, NOT A SHIFT. h2of_var.yaml places the published
# envelope in a window and is bit-identical to h2of.yaml at start=0, length=1;
# length_range is [0.125, 1.0] so window-filling notes stay reachable and
# roughly a ninth of the set is drawn from the old distribution. Nothing was
# removed from the space -- see the config, which explains the warp.
#
# EXPECT THE ABSOLUTE NUMBERS TO GET WORSE, and do not read that as a
# regression. The estimator's output space is unchanged -- START and LENGTH are
# not in save_params, and it still predicts harmor_amplitudes as a free
# per-frame curve -- but it now has to locate the note in time as well as shape
# it, which is more variation at the same capacity. The ARM ORDERING is what
# carries the result, and the number to compare against is not the old ID
# column but the old family evaluated on the same out-of-domain audio.
#
# PER-TERM WEIGHTS ARE 1/12 ON ALL THREE ARMS, which is what makes the
# comparison single-variable. hybridx carries two terms over six FFT sizes at
# sw_w 1.0; magx_halfw and logx_halfw carry one term each and run sw_w 0.5 to
# land on the same 1/12. ds_eval_folder prints this column from each run's own
# resolved config and warns if they diverge -- check it before reading any
# result.
#
# NO real_* BRANCHES HERE. resume_real switches the 200-400 loader to NSynth,
# and this experiment is about what a model trained ONLY on synthetic audio
# transfers to. Adding them doubles the cost for a question this run is not
# asking; they mirror the lines below with resume_real if that changes.

ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var

# STAGE base
# 0 -> 50, the shared pretrain every arm branches from. A NEW base is required
# rather than reusing pre_base: that one saw the published distribution, and
# branching the arms off it would put 50 epochs of the old data underneath
# every one of them.
ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var scripts/ds_run.sh pre_var_base pretrain "{gpu}" trainer.max_epochs=50 trainer.checkpoint_every_n_epochs=50

# STAGE variants
# 50 -> 200, the crossfade. The losses first differ during this phase.
ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var RESUME=pre_var_base CKPT=ep0049.ckpt scripts/ds_run.sh pre_var_magx_halfw pretrain "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.log_mag_w=0 model.sw_loss.power=1 schedule.sw_w.end_v=0.5
ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var RESUME=pre_var_base CKPT=ep0049.ckpt scripts/ds_run.sh pre_var_hybridx    pretrain "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.power=1 model.sw_loss.log_eps_v=1e-2
ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var RESUME=pre_var_base CKPT=ep0049.ckpt scripts/ds_run.sh pre_var_logx_halfw pretrain "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.power=1 model.sw_loss.log_eps_v=1e-2 model.sw_loss.mag_w=0 schedule.sw_w.end_v=0.5

# STAGE resumes
# 200 -> 400, spectral only, still on the synthetic set.
ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var RESUME=pre_var_magx_halfw scripts/ds_run.sh synth_var_magx_halfw resume_synth "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.log_mag_w=0 model.sw_loss.power=1 schedule.sw_w.end_v=0.5
ID_DIR=external/diffsynth/data/diffsynth_5-6/harmor_2oscfree_var RESUME=pre_var_hybridx    scripts/ds_run.sh synth_var_hybridx    resume_synth "{gpu}" trainer.checkpoint_every_n_epochs=50 model.sw_loss.power=1 model.sw_loss.log_eps_v=1e-2
