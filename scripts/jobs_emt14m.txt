# emt14m: emt14's three arms at MULTI-RESOLUTION. Nothing else moves.
#
#   tmux new -d -s emt14m 'python scripts/gpu_queue.py --jobs scripts/jobs_emt14m.txt 2>&1 | tee -a logs/emt14m.log'
#
# WHY. The plate's L1_STFT family is a SINGLE 4096 by construction -- the
# decomposition in losses.py isolates resolution as its own variable, and
# _MSS_RES is the arm that varies it. diffsynth's SpecWaveLoss runs six sizes
# for every arm. So "the same loss in both systems" held for the compression
# and the epsilon and NOT for the scale set, which is a difference a reader
# would reasonably read as an oversight rather than as a controlled variable.
#
# These arms remove it. L1_STFT_m5 / _eps1e2_m5 / _hyb1e2_m5 are the same
# linear / log / hybrid at {512, 1024, 2048, 4096, 8192} -- octave-spaced,
# keeping the 4096 the existing arms use so the single-resolution result stays
# nested inside the new set rather than being replaced by an unrelated one.
# Same epsilon (1e-2 on magnitude), same per-term weights, same schedule.
#
# RESUMES emt14's own pretrain, so each arm runs 7500 steps, not 10000.
# train_encoder sets start_step = ck["step"] + 1, so the counter continues
# rather than restarting: emt14_pre ran STEPS=2500 and these pick up at 2501.
# Pretrain and resume therefore share ONE 10000-step axis, and with
# --param-hold-frac 0.25 the parameter-only phase is steps 0-2500 -- which is
# precisely what emt14_pre already ran. The crossfade (2500-6250) and the
# spectral-only phase (6250-10000) are what happens here, so the spectral loss
# is engaged for every step these jobs run.
#
# emt14_pre itself used --param-hold-frac 1.0, holding the spectral fraction at
# zero throughout, so its checkpoint does not depend on which spectral loss its
# job line named. That is why all three emt14 arms already share the one file
# and why it does not need re-running for a new loss.
#
# WRITES TO results/ddsp/emt14m, NOT results/ddsp/emt14. The emt14 checkpoints
# are what emt14_listen_8k, every convolved evaluation and four listening tests
# were built from; overwriting them would leave all of that unreproducible.
